Git & GitHub Practical Guide

Step-by-step workflow for initializing local repositories, staging, committing, and pushing code to GitHub.

Version Control System
Pushing to GitHub: Fixing 403 Permission Denied

If git push -u origin main gives "Permission to 6-BharviBhangale/Assignment-1.git denied", this happens because your Windows Credential Manager has stored a different account login.

Two Quick Solutions:
  1. Using Personal Access Token (PAT): Run git push https://<YOUR_GITHUB_TOKEN>@github.com/6-BharviBhangale/Assignment-1.git main
  2. Or in Windows: Open Control Panel → User Accounts → Credential Manager → Windows Credentials, find git:https://github.com and update it with Bharvi's login!
1 Configure Git User Identity

Sets the committer name and email address recorded with every snapshot.

git config --global user.name "Bharvi Bhangale"
git config --global user.email "bharvibbhangale@gmail.com"
2 Initialize Local Repository

Creates a hidden .git/ directory tracking file revisions.

git init
3 Stage & Commit Files

Move modified files to the staging index, then capture a permanent snapshot.

git add .
git commit -m "feat: complete Web Technology assignments 1 to 9"
4 Link Remote GitHub Repository & Push

Point your local branch to your GitHub repository and upload commits.

git branch -M main
git remote add origin https://github.com/6-BharviBhangale/Assignment-1.git
git push -u origin main
Viva Voce Questions & Answers
Q1: What is the difference between git pull and git fetch?

git fetch downloads commits from the remote repository without altering your local files. git pull performs a fetch followed immediately by a merge into your active branch.

Q2: Why is the .gitignore file necessary?

It prevents sensitive keys (.env), heavy dependency folders (node_modules), and build outputs from cluttering your repository history.

Q3: How do you resolve a Git merge conflict?

Open the conflicted files, search for conflict markers (<<<<<<<, =======, >>>>>>>), manually pick desired code, remove markers, stage with git add, and run git commit.
