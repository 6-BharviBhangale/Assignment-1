🎓 Common Viva Voce Questions & Answers
Q1: What does REST stand for and what are its principles?

REST stands for Representational State Transfer. Principles include: Statelessness (no client session saved on server), Client-Server architecture, Cacheability, Uniform Interface, and Resource identification using URI endpoints.

Q2: What is the difference between PUT and PATCH?

PUT completely replaces an existing resource with the incoming representation. PATCH applies partial modifications to selected fields without touching the rest.

Q3: Why is CORS middleware necessary?

CORS (Cross-Origin Resource Sharing) allows frontend applications running on one port (e.g. 5500) to securely request APIs hosted on a different port (e.g. 5000 or 4000) without browser security blocks.
