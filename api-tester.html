Where REST API is Used & Defined

The REST API is implemented in Node.js using Express routing. It maps standard HTTP verbs to URI endpoints:

1. Route Definitions (`routes/studentRoutes.js`):
router.get('/', studentController.getAllStudents); // GET /api/students router.post('/', studentController.createStudent); // POST /api/students router.get('/:id', studentController.getStudentById); // GET /api/students/:id router.put('/:id', studentController.updateStudent); // PUT /api/students/:id router.delete('/:id', studentController.deleteStudent);// DELETE /api/students/:id
2. Frontend Client Consuming the REST API (`fetch`):
// Inside browser UI const res = await fetch('http://localhost:5000/api/students', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: "Bharvi", marks: [95, 92, 94, 91, 96] }) }); const newDocument = await res.json(); // HTTP 201 Created

Where MongoDB is Used & Defined

MongoDB stores documents in the students collection via Mongoose ODM in models/Student.js:

1. Mongoose Schema (`models/Student.js`):
const studentSchema = new mongoose.Schema({ name: { type: String, required: true }, rollNo: { type: String, required: true, unique: true }, department: { type: String, required: true }, marks: { type: [Number], required: true }, totalMarks: Number, percentage: Number, grade: String }, { timestamps: true }); // Automatically adds createdAt, updatedAt const Student = mongoose.model('Student', studentSchema);
2. Database Queries in Controller (`controllers/studentController.js`):
// CREATE in MongoDB const doc = await Student.create(req.body); // db.students.insertOne() // READ in MongoDB const docs = await Student.find(); // db.students.find({}) // UPDATE in MongoDB await Student.findByIdAndUpdate(id, { $set: updateData }); // db.students.updateOne() // DELETE in MongoDB await Student.findByIdAndDelete(id); // db.students.deleteOne()
🎓 High-Scoring Viva Voce Questions on MongoDB & REST APIs
Q1: What is Mongoose and why do we use it with MongoDB?

Mongoose is an Object Data Modeling (ODM) library for Node.js. It manages relationships between data, provides schema validation, translates between code objects and MongoDB documents, and simplifies complex queries.

Q2: What is the `_id` field in a MongoDB document?

Every MongoDB document automatically receives a unique 12-byte identifier called _id (an ObjectId). It consists of a 4-byte timestamp, 5-byte random value, and a 3-byte incrementing counter, serving as the document's primary key.

Q3: What makes a REST API "Stateless"?

Statelessness means the server does not store any client context or session state between requests. Every single incoming HTTP request must contain all the information necessary to authenticate, understand, and fulfill that request.

Q4: Why does POST return 201 Created while PUT returns 200 OK?

201 Created specifically indicates that a brand new resource document was successfully instantiated and assigned an identity (`_id`). 200 OK indicates that an existing resource was successfully updated or processed.
