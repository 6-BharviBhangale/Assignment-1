Localhost Ports & Server Guidance

If you encountered http://localhost:400, note that port 400 is a reserved network port. The actual lab servers run on:

  • Assignment 8 (Student Records API): http://localhost:5000
  • Assignment 9 (CRUD Mini Project): http://localhost:4000

Node.js servers require node server.js to be running in terminal. Don't worry! This page features an In-Browser Simulated REST Engine that lets you test all CRUD requests immediately without terminal setup!
